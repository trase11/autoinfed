# Αυτόματες ανακοινώσεις σχολών στο Instagram

Κάθε ώρα διαβάζει το RSS κάθε τμήματος και ανεβάζει τις νέες ανακοινώσεις ως post
(εικόνα + λεζάντα με link) στον λογαριασμό Instagram του αντίστοιχου συλλόγου.
Τρέχει δωρεάν στο GitHub Actions και δεν χρειάζεται server.

## Στήσιμο (μία φορά)

### 1. Repo στο GitHub
1. Φτιάξε **δημόσιο** repo (π.χ. `uni-announcer`) και ανέβασε όλα τα αρχεία.
   Πρέπει να είναι δημόσιο, γιατί το Instagram κατεβάζει τις εικόνες από το
   `raw.githubusercontent.com`. Τα tokens μένουν κρυφά στα Secrets.
2. **Settings → Actions → General → Workflow permissions → Read and write**.

### 2. Λογαριασμοί Instagram (για κάθε σύλλογο)
- Στην εφαρμογή Instagram: **Ρυθμίσεις → Τύπος λογαριασμού → Επαγγελματικός**
  (Creator ή Business).
- Σελίδα Facebook **δεν** χρειάζεται με αυτόν τον τρόπο σύνδεσης.

### 3. Εφαρμογή Meta και tokens (Unified login)
Οι εφαρμογές που φτιάχνονται από τα τέλη Οκτωβρίου 2026 έχουν μόνο το
**API setup with Unified login**. Τα tokens του **δεν λήγουν ποτέ**.
1. Η εφαρμογή πρέπει να ανήκει σε **business portfolio** (App settings → Basic → Business portfolio).
2. **Use cases → Instagram API → Customize → Permissions and features**: πρόσθεσε τα
   `instagram_basic` και `instagram_content_publish`.
3. **API setup with Unified login → Generate access tokens**: πρόσθεσε κάθε λογαριασμό
   (στο development mode ως Instagram Tester) και αποδέξου την πρόσκληση στο instagram.com →
   Settings → Website permissions → Apps and websites → Tester invites.
4. **Generate token** δίπλα σε κάθε λογαριασμό. Αν σε ρωτήσει για λήξη, διάλεξε **Never**.

### 4. Secrets στο GitHub (Settings → Secrets and variables → Actions)
- **`IG_TOKENS`**: ένα JSON με το `id` του config και το token του καθενός:
  ```json
  {"mie": "EAA...", "arch": "EAA..."}
  ```
  Αν στο log εμφανιστεί «Δεν βρέθηκε αυτόματα ο λογαριασμός», βάλε και το ID του
  λογαριασμού Instagram (φαίνεται δίπλα στον λογαριασμό στο Generate access tokens):
  `{"mie": {"token": "EAA...", "ig_id": "1784..."}}`
- **`GH_PAT`**: χρειάζεται **μόνο** για τα παλιά tokens που ξεκινούν με `IGAA` (λήγουν σε
  60 μέρες). Με Unified login δεν χρειάζεται.

### 5. Σύλλογοι
Άνοιξε το `config.yaml` και πρόσθεσε ένα block για κάθε σύλλογο.
Τα περισσότερα site τμημάτων είναι WordPress, οπότε το RSS είναι `https://site/?feed=rss2`.
Αν αυτό είναι άδειο, δοκίμασε `https://site/news/feed/` (έτσι είναι στο econ και στο civ).
Για site **χωρίς RSS** (π.χ. το arch) βάλε `type: html` και `url:` τη σελίδα
ανακοινώσεων. Το script βρίσκει μόνο του τίτλο και ημερομηνία σε κάθε ανακοίνωση.
Αν κάποτε αλλάξει η εμφάνιση του site και δεν βρει τίποτα, η εκτέλεση αποτυγχάνει
και το GitHub σου στέλνει email.

**Μετά την πρώτη εκτέλεση** άνοιξε το log στο Actions: για κάθε σύλλογο
γράφει τις 3 πιο πρόσφατες ανακοινώσεις που βρήκε. Έτσι βλέπεις αμέσως αν
διαβάζει σωστά κάθε site.

### 6. Πρώτη εκτέλεση
**Actions → Έλεγχος ανακοινώσεων → Run workflow.**
Στην πρώτη εκτέλεση οι ήδη υπάρχουσες ανακοινώσεις σημειώνονται ως «γνωστές» και
**δεν** ανεβαίνουν, ώστε να μη γεμίσει ο λογαριασμός με παλιά posts. Από εκεί και
πέρα ανεβαίνουν μόνο οι καινούριες. Αν θέλεις να ανέβουν και μερικές πρόσφατες,
άλλαξε το `first_run_posts` στο config.

## Χρήσιμα
- **Δοκιμή χωρίς Instagram:** `python announcer.py --dry-run`. Φτιάχνει μόνο τις εικόνες στο `images/`.
- **Ένας σύλλογος μόνο:** `python announcer.py --only mie`
- **Αν κάτι αποτύχει,** ξαναδοκιμάζει την επόμενη ώρα, έως 3 φορές.
  Το log φαίνεται στο Actions και το GitHub σου στέλνει email όταν μια εκτέλεση αποτύχει.
- **Όριο:** 100 posts ανά λογαριασμό το 24ωρο. Με `max_posts_per_run: 4` δεν το πλησιάζεις.
- **Η ώρα στο GitHub Actions δεν είναι ακριβής:** μια εκτέλεση μπορεί να καθυστερήσει 5–20 λεπτά.

## Έγκριση & επεξεργασία από το Telegram
Με `approval: telegram` στο config, κάθε νέα ανακοίνωση έρχεται πρώτα στο
Telegram bot με την εικόνα, τη λεζάντα και κουμπιά **✅ Ναι / ❌ Όχι**.
Οι απαντήσεις διαβάζονται στον επόμενο έλεγχο (κάθε ~15 λεπτά).

Για αλλαγές, κάνε **Απάντηση (reply)** στο μήνυμα με την εικόνα και γράψε:
- σκέτο κείμενο → γίνεται ολόκληρη η λεζάντα του post
- `τίτλος: …` → νέος τίτλος στην εικόνα (και στη λεζάντα, αν δεν έχεις γράψει δική σου)
- `περίληψη: …` → νέο κείμενο κάτω από τον τίτλο στην εικόνα

Μετά από κάθε αλλαγή έρχεται νέα προεπισκόπηση, που θέλει ξανά ✅.

## Δικές σου ανακοινώσεις / καρουσέλ από το Telegram
Κάτω στο Telegram υπάρχουν μόνιμα κουμπιά:
1. **📝 Νέα: <σύλλογος>** — ξεκινά πρόχειρο για αυτόν τον λογαριασμό
2. γράψε τον **τίτλο** (μπαίνει στο εξώφυλλο με το template της καμπάνιας)
3. στείλε **φωτογραφίες** (προαιρετικά) — γίνονται σελίδες του καρουσέλ με τη σειρά που τις στέλνεις (έως 10 συνολικά)
4. γράψε τη **λεζάντα** του post (προαιρετικά· αλλιώς μπαίνει ο τίτλος)
5. **✅ Τέλος** → έρχεται προεπισκόπηση του καρουσέλ με ✅/❌

- **🖼 Δικό μου εξώφυλλο**: η 1η φωτογραφία γίνεται εξώφυλλο αντί για το template.
- **🗑 Ακύρωση**: πετάει το πρόχειρο.
- Τα κουμπιά εμφανίζουν μόνο λογαριασμούς που έχουν token στο `IG_TOKENS`.
- Για να ξαναεμφανιστούν τα κουμπιά: στείλε `/start`.
